## 핵심 문제와 해법

- **문제**: 중소기업 공공구매 시장은 연 **126.2조 원** 규모이지만, 정부 인정 혁신제품조차 3개 중 1개(**31.5%**)는 구매실적이 0건이며 전체 공공조달의 **38.9%**는 나라장터 밖 자체조달·비전자 거래입니다.
- **해법**: 공고가 뜬 뒤 경쟁하는 기존 입찰알림·서류 자동화 도구가 아니라, **공고 이전(예산 편성 · 발주계획 · 사전규격)**과 **비입찰 경로(수의계약 · 시범구매 · 구매상담회)**에서 *"누구에게·언제·무엇을"* 실행할지 안내합니다.

## 페이지 구성 (4-Page Static MVP)

| 페이지 | 파일 | 주요 기능 |
|---|---|---|
| **서비스 소개 (랜딩)** | `index.html` | 공고 이전 vs 이후 타임라인, 4단계 인터랙티브 쇼케이스(간이 자가진단 포함), 충남 환경센서 시나리오, 4축 경쟁 비교표 + 2×2 포지셔닝 매트릭스, 3단 기관 요금, 로드맵, 근거 출처 21건 |
| **진입 준비도 진단** | `diagnosis.html` | 4개 영역(등록·인증 / 납품 실적 / 제안 자료 / 기관 이해) 20문항 체크리스트, 실시간 점수·보완 사항, `2주·1개월·3개월` 행동 리포트 및 PDF 인쇄 |
| **수요 레이더·구매지도** | `radar.html` | 사전규격·발주계획·수의계약·시범구매 필터 탐색기 + 충남 4개 기관 유형(기초지자체·교육청·지방공단·광역지자체)별 구매결정 경로·예산 시기·수의계약 한도 맵 |
| **지원기관 대시보드** | `dashboard.html` | 소속 기업 `진단 → 접촉 → 제안 → 계약` 클릭 필터 퍼널, 월간 성과 KPI, 기업별 단계 변경 시 실시간 퍼널·KPI 연동 |

## 폴더 구조

```text
.
├── index.html            # 공식 랜딩페이지
├── diagnosis.html        # 20문항 진입 준비도 진단 & 행동 리포트
├── radar.html            # 수요 레이더 & 충남 기관 구매지도
├── dashboard.html        # 지원기관 단계관리 대시보드
├── css/
│   └── style.css         # 공통 디자인 시스템 (딥 네이비 + 웜 오렌지, 반응형, 인쇄 스타일)
├── js/
│   ├── common.js         # 공통 네비게이션, 모달, FAQ, 스크롤 리빌
│   ├── home.js           # 랜딩 쇼케이스 탭 & 간이 진단
│   ├── diagnosis.js      # 20문항 규칙 기반 채점 & 행동 리포트 생성
│   ├── radar.js          # 수요 필터 & 기관 구매지도 전환
│   └── dashboard.js      # 지원기관 퍼널 & 기업 단계 관리
├── assets/
│   ├── favicon.svg       # 경량 SVG 파비콘
│   ├── og-image.svg      # 소셜 공유용 Open Graph 이미지
│   └── fonts/            # Pretendard 1.3.9 경량 subset woff2 (5종)
├── robots.txt
└── sitemap.xml
```

## 로컬 실행 방법

별도의 빌드 도구나 외부 CDN 의존성 없이 정적 서버로 바로 실행할 수 있습니다.

```bash
python -m http.server 8765
# 브라우저에서 http://localhost:8765/ 접속
```

## 안내 사항

- `radar.html`과 `dashboard.html`에 표시되는 개별 기업명·수요 건·진행 수치는 서비스 흐름과 와이어프레임을 설명하기 위한 **시연용 가상 예시 데이터**입니다.
- 시장 규모 및 공공구매 관련 거시 통계는 사업계획서 붙임 3의 공식 보도자료·통계(중소벤처기업부, 조달청, 국회예산정책처 등)를 근거로 하며, `index.html` 하단에서 원문 출처를 확인할 수 있습니다.
